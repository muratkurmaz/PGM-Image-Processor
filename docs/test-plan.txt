Before all the programs are written, I start by writing the main modules that will be common to all of them.
These are modules for reading and writing the pgm file. First, I will write the readPgm documentation and helper modules.
These helper modules will be used to allocate memory and pass comments.
Then I read a pgm file with a size of 13 * 13 with readPgm and printed the information on the screen.
After making sure that the output in the terminal and the content of the pgm file are the same, I proceed to write the writePgm module.
I wrote a simple pgmEcho program to test that it works properly.
I made comparisons by looking at the content of two images encoded as ascii with Notped++.
Thus, I have obtained a main library that I can use in all my other pgm programs.
Now it's time to add different pgm modules to this library that I will use in other programs.
I have to test with wrong argument entries for every program I write. All passed the test.
At the same time, I tested the programs to give a warning by giving a corrupt file to each program.
